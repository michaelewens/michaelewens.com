## Prompt for Replit (copy/paste)

You are editing my existing single-file webpage exercise at `mic_exercise.html` hosted on my personal site. Please update the file by **adding an interactive student worksheet** with **two columns** (Column 1 and Column 2) embedded under the “Your Task (3 minutes)” section. Keep the original case text intact above it.

### Goal / UX
Students should be able to:
1) **Enter their ideas** for Part A in Column 1 (organized into buckets).
2) In Column 2, see the **filter prompt** and then **tag** each idea with $$ / C / R / ! and **select their top two initiatives** for the next 12 months.
3) Everything should work without any backend: pure HTML/CSS/JS in the same file.
4) Work well on laptop and mobile (responsive).
5) Persist their inputs in the browser using `localStorage` so refresh doesn’t delete work.
6) Provide buttons to **Add idea**, **Edit**, **Delete**, **Clear all**, and **Export** (copy to clipboard as text).

### Where to insert
Insert the new UI **below** the “Your Task (3 minutes)” instructions (after the list of questions) and **above** any footer text.

### Column layout
Create a container with two side-by-side columns on desktop, stacked on mobile.

#### Column 1: “Part A — Management Team”
Header text: “Part A — Management Team (enter ideas)”
Subtext: “Pick two improvements. Add as many candidate ideas as you want.”

Provide three sections (buckets) with “Add idea” controls:
- **EBITDA / Margin**
- **Cash (Working Capital)**
- **Growth**

For each section:
- A text input (single-line) + “Add” button.
- Added ideas appear as a list of cards/rows.
- Each idea row includes:
  - The idea text
  - An **Edit** icon/button
  - A **Delete** icon/button

Data model requirement:
Each idea should be stored as an object with:
- `id` (unique string)
- `bucket` ("margin" | "cash" | "growth")
- `text`
- `tags` (array, initially empty)
- `topPick` (boolean, initially false)

#### Column 2: “Filter — Ownership Constraint”
Header text: “Column 2 — Filter”
Subtext should show this prompt exactly:

“Tag each idea:
- $$ = fast EBITDA
- C = releases cash
- R = reduces risk / improves exit multiple
- ! = high disruption / volatility

Then re-rank: pick your TOP 2 for the next 12 months.”

Under the prompt, display **all ideas from Column 1** in one combined list (still showing their bucket label). For each idea row include:
- Bucket label (e.g., “Margin”, “Cash”, “Growth”)
- Idea text
- Four toggle buttons for tags: `$$`, `C`, `R`, `!` (multiple tags allowed)
- A checkbox or star toggle: “Top 2 pick”
- Visual state changes when toggles are on (e.g., colored pill/badge)

Rules:
- Students can mark at most **two** ideas as “Top 2 pick”. If they try a third, show a small inline warning and prevent it.
- Sorting: by default show ideas in the order entered. Add an optional “Sort by bucket” toggle.

### Buttons / utilities
Below the two columns add a small toolbar:
- **Export / Copy summary** button:
  - Copies a formatted text summary to clipboard like:

Part A Ideas:
Margin:
- …
Cash:
- …
Growth:
- …

Tagged + Top Picks:
- [Top Pick] (Margin) Idea text — tags: $$, R
- (Cash) Idea text — tags: C
etc.

- **Clear all** button:
  - Confirms with the user then clears localStorage and resets UI.

### Visual design
- Use clean, classroom-friendly styling consistent with the existing page (simple typography).
- Use CSS variables if possible.
- Cards should have subtle borders and spacing.
- Make tag toggles look like small pills/buttons.

### Technical constraints
- No external JS frameworks (no React/Vue). Vanilla JS only.
- You may use minimal external CSS only if already used by the page; otherwise keep it inline or in a `<style>` block.
- Code should be readable and commented.
- Ensure it does not break existing content/layout.

### Implementation details
- On page load: read from `localStorage` key `micIdeasV1`. If present, render ideas and states.
- On any add/edit/delete/tag/topPick change: update the array and re-save to localStorage.
- Use event delegation for performance and simpler code.
- Generate ids using something like `crypto.randomUUID()` when available; fallback to timestamp+random.

### Acceptance criteria
- Students can add/edit/delete ideas in Column 1.
- Column 2 automatically reflects all ideas and allows tagging + Top 2 selection with the two-pick limit.
- All state persists on refresh.
- Export copies a clean summary to clipboard.
- Mobile responsive (columns stack).

After implementing, briefly explain where in the HTML you inserted the new UI and what localStorage key is used.
